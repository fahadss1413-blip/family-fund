# صندوق العائلة

تطبيق أولي خاص بإدارة صندوق العائلة.

## الوظائف الحالية
- تسجيل الأعضاء بالاسم ورقم الجوال.
- تحديد القطّة الشهرية.
- تعديل الرصيد من لوحة المشرف.
- تسجيل السداد للأعضاء.
- سجل السلف، وحالة السداد.
- لوحة المشرف منفصلة عن واجهة الأعضاء.

> هذه نسخة أولية للتجربة. بياناتها محفوظة محليًا في المتصفح، وليست قاعدة بيانات إنتاجية بعد.
